## 2025-02-23 - Add Tooltips to Icon-Only Buttons
**Learning:** Adding custom tooltips to buttons while leaving the native `title` attribute intact results in a clunky, redundant UX where both tooltips appear simultaneously on hover.
**Action:** Always remove the native `title` attribute when wrapping elements in a custom `<Tooltip>` component, relying instead on `aria-label` for screen reader accessibility and the custom tooltip for visual feedback.
