## 2024-03-01 - Add ARIA Labels to QuickScanModal and StorageMatrix
**Learning:** Icon-only buttons often lack accessible names, making them difficult for screen reader users to understand. This is a common accessibility issue in React applications. While English is the default language of the application based on the surrounding UI text, ensuring accessibility tags match the application language is critical.
**Action:** Always add `aria-label` to buttons that only contain icons. Ensure the language used for the `aria-label` matches the primary language of the application's UI to maintain a consistent experience for screen reader users.
