## 2026-07-06 - ImportWizard Radio Button Grouping and File Input a11y
**Learning:** `input type="file"` when hidden (`opacity-0`) inside a custom drop zone requires an `aria-label` or `title` to be read correctly by screen readers. Also, when creating custom radio button components, relying solely on nested `<label><input/></label>` can cause issues on some assistive technologies. Furthermore, missing the `name` attribute on grouped radio buttons completely breaks native keyboard navigation (arrow keys).
**Action:** When implementing custom file uploads or radio groups, explicitly pair `<label htmlFor="id">` and `<input id="id">`, and always provide a `name` attribute to link the radio inputs as a group for proper keyboard accessibility.
