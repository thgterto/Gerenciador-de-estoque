## 2025-05-18 - XSS Risk in document.write
**Vulnerability:** XSS vulnerability found in `src/components/Modals.tsx` and `labcontrol-spfx/src/webparts/labControlApp/components/Modals.tsx`. The `handlePrint` function of the QRGeneratorModal component used `document.write` to generate a printable page and directly interpolated object properties like `item.name`, `item.lotNumber`, and `item.id`.
**Learning:** React escapes interpolated values automatically, but when we generate raw HTML strings for `document.write` or `dangerouslySetInnerHTML`, that protection is bypassed. If any of those user-provided values contained `<script>` or other HTML tags, it would be executed in the context of the print window.
**Prevention:** Avoid `document.write` entirely if possible. If you must construct raw HTML strings, ensure that all user-provided data is passed through an HTML entity escaping function before interpolation.
