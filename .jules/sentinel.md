## 2025-05-18 - [Information Exposure in API Controllers]
**Vulnerability:** Fastify route handlers in `server/src/adapters/controllers/InventoryController.ts` were returning the raw `error.message` to the client in 500 response bodies. This could expose internal database queries, file paths, or third-party API keys present in the error context.
**Learning:** Always use a generic error message for 500 status codes. Fastify supports a global error handler, but when overriding it locally with try/catch, developers must manually log the error (e.g., `req.log.error(error)`) and send a safe response string (e.g., `'Internal Server Error'`).
**Prevention:** Avoid manually sending `error.message` in 500 responses. Standardize on passing errors to Fastify's global error handler, or explicitly log and return generic strings.
