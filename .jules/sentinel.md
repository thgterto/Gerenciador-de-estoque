## 2026-04-03 - [Fix XSS via print document.write]
**Vulnerability:** XSS vulnerability where unescaped user input (such as item name or lot number) was injected directly into HTML string via `document.write` during the QR Code printing functionality.
**Learning:** `document.write` is used to dynamically construct HTML strings for printing via a popup window. While functionally working, using raw variable interpolations introduces XSS risks if malicious input is entered into item property fields like name. Also, using string methods directly on unknown types caused a potential crash; `String()` coercion guarantees `.replace` exists.
**Prevention:** Avoid unescaped direct interpolation of variables into HTML using `document.write` or `dangerouslySetInnerHTML`. Always use an `escapeHtml` utility (with proper string coercion) or better yet, safe DOM creation APIs.
