## 2024-05-15 - [Fix XSS vulnerability in QR code printing]
**Vulnerability:** XSS vulnerability in `handlePrint` function of QR generator modal where user-controlled input (`item.name`, `item.lotNumber`, `item.id`) was directly interpolated into `printWindow.document.write()`.
**Learning:** `document.write` combined with untrusted data creates a direct DOM XSS vector. React's built-in escaping does not protect against vulnerabilities when creating entirely new DOM structures manually outside of React's lifecycle. Also, the `Modals.tsx` file is duplicated across two locations (`src/components/Modals.tsx` and `labcontrol-spfx/src/webparts/labControlApp/components/Modals.tsx`).
**Prevention:** Always use an `escapeHtml` utility when constructing raw HTML strings with template literals, especially when passing them to APIs like `document.write` or `innerHTML`. Ensure fixes are applied to all duplicated files.
