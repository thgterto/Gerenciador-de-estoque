## 2025-05-18 - [Fix DOM XSS in QR Generator Modal Print Window]
**Vulnerability:** A DOM-based XSS vulnerability was identified in `src/components/Modals.tsx` and `labcontrol-spfx/src/webparts/labControlApp/components/Modals.tsx`. The code used `printWindow.document.write` to dynamically inject HTML that included unsanitized user inputs (`item.name`, `item.lotNumber`, `item.id`).
**Learning:** `insertAdjacentHTML` combined with `escapeHtml` is an effective method for mitigating DOM XSS, avoiding the problematic `document.write`. Scripts injected via `insertAdjacentHTML` are NOT executed by modern browsers, so when programmatic features like `window.print()` are needed, script tags must be explicitly created using `document.createElement('script')` and injected via `appendChild()`.
**Prevention:** Always sanitize user inputs when constructing HTML strings manually. Prefer `createElement` and `textContent` or use an HTML escaping helper before injecting into the DOM, and avoid `document.write` completely.
