## 2026-04-04 - [Remove regex.exec() to prevent Code Injection in SqlParser.ts]
**Vulnerability:** The `SqlParser.parseInsertValues` method utilizes `regex.exec(inner)` in a while loop to parse user-controlled input. This can lead to ReDoS (Regular Expression Denial of Service) or potential logic manipulation through unhandled edge cases depending on the environment.
**Learning:** `regex.exec` used inside a loop with arbitrary user data and complex regular expressions can create infinite loops or severe performance bottlenecks if not carefully controlled.
**Prevention:** Re-evaluate parsing strategies: if standard patterns like CSV strings or JSON-like syntax are present, avoid complex regex matching in favor of safer splitting or dedicated AST parsers. In cases where `regex.exec()` is necessary, ensure string lengths are checked, or prefer safer built-in APIs.
