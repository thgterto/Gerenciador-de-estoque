## 2025-06-15 - [DOM-based XSS in Print Label functionality]
**Vulnerability:** DOM-based Cross-Site Scripting (XSS) vulnerability found in the `handlePrint` function of the Modals.tsx components, which directly interpolated object properties (e.g., `item.name`, `item.lotNumber`, `item.id`) into an HTML template passed to `printWindow.document.write()`.
**Learning:** The use of `document.write()` to render dynamic data without proper sanitization can expose the application to DOM-based XSS, allowing malicious scripts embedded in user inputs (like product names or lot numbers) to execute within the context of the opened print window.
**Prevention:** Always sanitize or escape user-controlled data before interpolating it into HTML contexts. Using a utility function like `escapeHtml` to convert dangerous characters (`&`, `<`, `>`, `"`, `'`) into their corresponding HTML entities ensures that the data is treated as plain text rather than executable code. Avoid `document.write()` when possible; prefer modern DOM manipulation methods or templating engines that handle sanitization automatically.
