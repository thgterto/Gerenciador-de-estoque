## 2025-05-18 - XSS via printWindow.document.write
**Vulnerability:** XSS vulnerability in `src/components/Modals.tsx` and `labcontrol-spfx/src/webparts/labControlApp/components/Modals.tsx` due to `document.write` with unsanitized inputs (`${item.name}`, `${item.lotNumber}`, etc.).
**Learning:** React escapes by default, but when manually constructing HTML strings and writing them directly into the DOM (e.g., in a popup window using `document.write`), that protection is bypassed. Need to ensure variables inserted into string templates for HTML are sanitized. Also need to ensure the variables being replaced are strings before calling `.replace()`.
**Prevention:** Avoid `document.write`. If HTML must be generated dynamically for a print window, properly escape variables (e.g., using a sanitization library or custom escaping function) before interpolating them into HTML strings.
