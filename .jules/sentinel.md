## 2023-10-27 - Information Exposure in Fastify Controllers
**Vulnerability:** Controller methods were explicitly catching errors and returning `res.status(500).send({ error: error.message });`. This leaks internal error details (like database query failures or stack traces) to the client.
**Learning:** Fastify natively handles unhandled promise rejections in `async` route handlers and securely masks internal error details using its centralized error handler (or default behavior), returning a generic "Internal Server Error" message when `NODE_ENV === 'production'`. Overriding this behavior with manual `try/catch` blocks that expose `error.message` introduces a security risk.
**Prevention:** Rely on Fastify's built-in async error handling or a centralized, secure error handler. Do not explicitly catch and return raw error messages to the client in route handlers.
