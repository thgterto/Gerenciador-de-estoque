## 2025-02-14 - React List Memoization and Stale Closures
**Learning:** When using `React.memo` with a custom `arePropsEqual` function for list rendering, you must be extremely careful to include ALL props (including functions) in the comparison unless you intentionally rely on stale closures. Omitting callback props can result in stale state being captured if the parent re-renders and the children do not update their callback references. Furthermore, inline objects created during `.map()` iteration (like a `style` object) will always fail strict reference equality (`prev.style === next.style`), causing memoized row components to re-render constantly and defeating the optimization.
**Action:** Always extract static objects (like styling) using `useMemo` outside of loops to provide stable references. Ensure all props, particularly callbacks, are included in custom `arePropsEqual` functions to prevent subtle state bugs.
