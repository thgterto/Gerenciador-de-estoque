## 2023-10-27 - [Optimize text search filtering]
**Learning:** Using `useMemo` to cache values calculated from `items` introduces a performance regression if the text search input itself is empty, because `useMemo` evaluates eagerly, calculating strings even when unnecessary. Lazy evaluation (by assigning a `_searchable` prop dynamically during filtering) ensures no unnecessary normalizations run when search isn't used, and provides up to a 10x speedup when search *is* used by caching results on the objects themselves without affecting `package.json`.
**Action:** Be mindful of eager vs lazy evaluation in memoized components. Avoid adding dependencies to `package.json` unless absolutely necessary.
